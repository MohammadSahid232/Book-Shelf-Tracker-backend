# BookShelf Tracker — Backend

All backend application source code is located inside this directory.

## Directory Structure

```
backend/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── middlewares/
│   ├── models/
│   ├── routes/
│   ├── services/
│   └── validators/
├── scripts/
├── server.js
├── index.js
├── package.json
├── package-lock.json
├── .env.example
└── .gitignore
```

## Getting Started

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```

4. Start development server:
   ```bash
   npm run dev
   ```
